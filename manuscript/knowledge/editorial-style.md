# 慈濟人文真善美文稿編採規則

本檔描述可操作的編採規則，不要求逐字模仿任何作者。語料統計見 `generated/`；正式規則以本檔、術語表與人工編審裁決為準。

## 1. 文稿的本質

慈濟文稿同時處理三件事：

1. **真**：時間、地點、人物、數字、行動與引言可追溯。
2. **善**：呈現具體善行與人際互動，不用抽象讚美取代事實。
3. **美**：透過場景、節奏與人物觀點讓讀者看見事件，但不為戲劇性扭曲現場。

順序固定為真 → 善 → 美。事實不足時停止，不以文學性填補。

## 2. 新聞稿與大藏經紀錄必須分開

### 即時新聞稿

- 優先回答事件、影響、數字與下一步。
- 導言短，第一段即交代新聞價值。
- 人物故事只保留最能說明事件的一段。
- 適合快速發布與對外說明。

### 社區大藏經／歷史紀錄

- 保留活動因緣、準備過程、團隊協作、人物故事與後續影響。
- 可以有較多小標與人物觀點。
- 目的在留史，而不是追求即時流量。

不得把完整活動流程塞進即時新聞稿，也不得把大藏經稿壓縮成只有組織宣傳語。

## 3. 標題

### 3.1 優先素材

依序選擇：

1. 最重要的具體行動。
2. 最清楚的成果或影響。
3. 最具代表性的現場畫面。
4. 人物的實際選擇或轉變。
5. 活動的精神主題。

### 3.2 常用結構

```text
行動＋成果
災情／困境＋回應
具體畫面＋精神意義
人物＋生命轉變
活動名稱＋精神主軸
事實層＋價值層
```

雙句標題的前半應提供可辨識事件，後半才提供影響或價值。前後都寫抽象價值詞等於沒有標題。

### 3.3 品質檢查

- 讀完標題能否知道文章大致在寫什麼？
- 是否把預計、期待或規劃寫成既成成果？
- 是否使用未經同意的人名、病況或家庭困境？
- 拿掉「愛、希望、溫暖、感恩」後是否仍有內容？
- 是否與正文最重要段落一致？

## 4. 導言

導言至少覆蓋 5W1H 中最重要的四項，不強迫一段塞滿所有資訊。

### 4.1 事實導言

適用：災害、發放、義診、重大合作、即時新聞。

```text
日期＋地點＋主辦／參與者＋行動＋主要成果或目的
```

### 4.2 場景導言

適用：人物、志工、營隊、宗教活動與社區紀錄。

先寫可觀察的聲音、動作、空間或物件，再迅速交代事件。場景不得由作者想像。

### 4.3 引言導言

只有當一句原話能建立核心衝突或主題時使用。引言後立即說明說話者、情境與事件。

### 4.4 禁止導言

- 「在這個充滿愛與希望的日子裡」等空泛句。
- 先用三段說理念，第四段才交代活動。
- 作者代替人物宣稱感動、悲痛或重燃希望。
- 把圖說或活動簡章原文直接貼成導言。

## 5. 段落骨架

### 5.1 災害救援稿

```text
導言：災情、地點、時間、主要行動
背景：災害影響與資料來源
評估：勘災、訪視、造冊、需求確認
行動：任務、團隊、物資、發放或修繕
人物：一至兩位經同意人物的具體處境與原話
成果：對帳後的戶數、人數、品項與完成狀態
後續：持續關懷、重建或下一階段
```

### 5.2 醫療義診稿

```text
導言：醫療需求、日期、地點、服務項目、受惠規模
因緣：合作單位與需求來源
專業行動：篩檢、診療、手術、藥物、追蹤
人物：病患原有困難、接受服務、實際改變
醫護觀點：經核准的專業說明
後續：複診、追蹤與可持續合作
```

醫療稿不得由非醫療人員推論診斷、療效或預後。

### 5.3 人物故事稿

```text
現在的場景
→ 過去的處境
→ 關鍵選擇
→ 具體行動
→ 困難與調整
→ 對他人或自己的影響
→ 未完成的下一步
```

人物不是履歷表。每一個性格判斷要有行動、原話或旁證支持。

### 5.4 社區／教育／志工活動稿

```text
活動因緣與目標
→ 一個核心設計或挑戰
→ 參與者如何投入
→ 一至兩個具體互動
→ 參與者觀點
→ 活動留下的能力、關係或後續
```

不得逐項抄寫流程表。

### 5.5 宗教與歲末活動稿

```text
儀式／活動因緣
→ 現場莊嚴或具體畫面
→ 法義或主題的正確來源
→ 參與者如何理解與實踐
→ 願心與後續行動
```

法義用詞需由核准來源確認，模型不得自行延伸開示。

## 6. 小標

小標的功能是推進故事，不只是美化版面。

常見段落功能：

```text
背景／因緣
需求／困境
評估／準備
行動／協作
人物／轉折
成果／影響
後續／願行
```

小標應概括緊接段落，避免每個小標都使用「愛、希望、溫暖」。同篇小標句型應有一致性，但不強迫押韻或對仗。

## 7. 人物與引言

### 7.1 引言前要有情境

先說明人物是誰、正在面對什麼、為何在此，再放原話。避免：

```text
某某感動地說：「……」
```

除非「感動」來自人物原話或可觀察行為，否則改成：

```text
完成資料核對後，某某談到等待期間的不確定，說：「……」
```

### 7.2 引言功能

- 證明事件與受益影響。
- 呈現困難或原始動機。
- 展示人物的選擇與轉變。
- 提供專業角色的判斷。
- 說明下一步期待。

每段引言應有功能，不為增加情緒而堆放。

### 7.3 引言編修

可刪除重複口頭贅詞，不能：

- 增加人物未說過的慈濟價值詞。
- 把間接轉述改成直接引言。
- 合併不同時間的話而不標示。
- 讓受訪者替組織背書超出原意。

## 8. 慈濟專業詞

專業詞分兩層管理。

### 8.1 制度與工作詞

例如勘災、訪視、造冊、發放、修繕、人醫會、功能組、合心、和氣、互愛、協力。這些詞要求定義與情境正確。

### 8.2 法脈與價值詞

例如感恩、尊重、愛、善念、初心、願力、法喜、精進、共善。這些詞要求節制並由具體行動支撐。

價值詞密度過高會使文章失去可信度。建議同一段不重複兩次以上相同價值詞；結尾若只是將多個價值詞串接，應重寫為具體後續。

## 9. 數字與口徑

任何數字寫入前通過五檢：

1. 分子、分母與計算口徑明確。
2. 時間窗一致。
3. 人數、戶數、份數、件數不混用。
4. 預估、登記、實到、完成與對帳後數字分開。
5. 同一數字在 Event、Task、Inventory、Fund 間一致，否則標待補。

中文數字或阿拉伯數字依編輯規範統一，不能在同一篇無規則混用。

## 10. 圖說

圖說回答：誰、何時、何地、正在做什麼、為何重要、攝影者。只描述畫面中可見或已核准的背景。

禁止：

- 從表情推測內心。
- 把整篇文章摘要塞進圖說。
- 圖說與正文完全重複。
- 漏掉攝影者或同意狀態。

## 11. 結尾

好的結尾回到：

- 已完成的具體改變。
- 下一步行動。
- 人物自己說出的期待。
- 事件對社區、家庭或團隊留下的影響。

避免固定以「愛與希望持續傳遞」「活動在感恩中圓滿」收尾。若沒有後續資訊，寧可簡潔停止於最後一個具體事實。

## 12. AI 仿寫警訊

出現下列情況應退回：

- 每段都出現感恩、溫暖、希望、圓滿、善念。
- 句型反覆為「不僅……更……」「這不只是……更是……」。
- 未提供事實卻宣稱生命被翻轉、希望重燃。
- 所有人都「感動地說」「深受感動」。
- 標題與結尾抽象，正文是活動流程。
- 把不同地區、宗教或文化背景寫成單一臺灣慈濟語氣。
- 對災民、病患與弱勢人物使用居高臨下的敘述。

## 13. 編審評分

每項 0–4 分，任一項低於 2 分不得發布。

| 項目 | 4 分標準 |
|---|---|
| 事實完整 | 重要事實皆可追溯，無口徑衝突 |
| 新聞／留史價值 | 主題清晰，知道為何值得記錄 |
| 人物呈現 | 有情境、行動、原話與主體性 |
| 結構 | 導言、小標、段落與結尾互相呼應 |
| 慈濟用語 | 專詞正確，價值詞由行動支撐 |
| 隱私尊嚴 | 同意完整，最低揭露，沒有苦難消費 |
| 語言品質 | 精確、自然、無流水帳與 AI 套話 |
| 圖文一致 | 圖說、照片與正文不矛盾、不重複 |

建議發布門檻：總分至少 26／32，且事實完整、隱私尊嚴均至少 3 分。
