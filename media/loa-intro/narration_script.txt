LINE OA 介紹影片・旁白腳本（9 句，逐景對應）
================================================

錄製方式二選一：
A. 手機錄音：每句錄一個檔（安靜環境、口語自然即可，前後留白程式會自動裁掉），
   檔名照 narr_0 ~ narr_8（wav / mp3 / m4a 皆可），放進 media/loa-intro/voice/。
B. 本機 edge-tts（台灣腔神經語音，需可連網的環境；雲端 container 網路政策擋 TTS，只能本機跑）：
   聲音選擇（VOICE 擇一）：
   - zh-TW-YunJheNeural  男・雲哲：沉穩教學感，最接近 PAPAYA 電腦教室風格
     （註：PAPAYA 本人 2026-06 受訪證實旁白是親錄真人聲，無法取得同顆聲線，雲哲是微軟唯一台灣腔男聲）
   - zh-TW-HsiaoChenNeural 女・曉臻：溫暖可愛，配本片畫風（用它時建議 rate='+4%', pitch='+12Hz'）
   pip install edge-tts
   python - <<'PY'
   import asyncio, edge_tts, pathlib
   VOICE = 'zh-TW-YunJheNeural'   # 換聲音改這行
   LINES = [
       "哈囉！我是救災 LINE 小幫手！一起來看看，我會做什麼吧！",
       "災區訊息又多又急？別擔心，一支手機就搞定！任務、回報、物資、平安，通通都在 LINE 裡。",
       "功能一，一鍵報到！到現場點一下，馬上完成報到，指揮中心立刻看見。",
       "功能二，任務卡直接送到手上！接單、婉拒，一顆按鈕搞定。",
       "功能三，進度隨手報！完成、受阻、拍照回傳，讓每一分用心，都被看見。",
       "功能四，物資三步叫料！選品項、填數量、送出，到貨簽收也是一鍵完成。",
       "功能五，一鍵報平安！安全點名輕鬆回覆，緊急求救，直達幹部。",
       "志工、班長、司機、香積、訪視、幹部，六種角色都有專屬選單，長輩也好上手！",
       "快加入好友，跟我們一起守護家園。科技幫忙，溫暖不減。感恩！",
   ]
   async def main():
       pathlib.Path('voice').mkdir(exist_ok=True)
       for i, l in enumerate(LINES):
           await edge_tts.Communicate(l, VOICE).save(f'voice/narr_{i}.mp3')
   asyncio.run(main())
   PY
   產出的 voice/ 資料夾放進 media/loa-intro/ 後 commit。

檔案就位後執行：python3 gen_audio.py && FFMPEG_BIN=... node render.js（詳見 gen_audio.py 開頭），
或直接跟 Claude 說「voice 檔上了」即可自動重混重渲。

旁白內容（口語版，可自行微調語氣）
------------------------------------------------
0.（開場）哈囉！我是救災 LINE 小幫手！一起來看看，我會做什麼吧！
1.（情境）災區訊息又多又急？別擔心，一支手機就搞定！任務、回報、物資、平安，通通都在 LINE 裡。
2.（功能一）功能一，一鍵報到！到現場點一下，馬上完成報到，指揮中心立刻看見。
3.（功能二）功能二，任務卡直接送到手上！接單、婉拒，一顆按鈕搞定。
4.（功能三）功能三，進度隨手報！完成、受阻、拍照回傳，讓每一分用心，都被看見。
5.（功能四）功能四，物資三步叫料！選品項、填數量、送出，到貨簽收也是一鍵完成。
6.（功能五）功能五，一鍵報平安！安全點名輕鬆回覆，緊急求救，直達幹部。
7.（角色）志工、班長、司機、香積、訪視、幹部，六種角色都有專屬選單，長輩也好上手！
8.（結尾）快加入好友，跟我們一起守護家園。科技幫忙，溫暖不減。感恩！
